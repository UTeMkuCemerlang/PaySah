# Tools and resources

The application uses TypeScript, Node.js 24, React, Vite, Express, PostgreSQL, Zod, Sharp, Tesseract.js and Three.js. Exact dependency versions and available package license metadata are preserved in package.json and package-lock.json; third-party licenses remain applicable.

Replit is used for application hosting and private receipt storage. RunPod is used for GPU receipt-field extraction with Qwen/Qwen2.5-VL-7B-Instruct. CPU OCR and synthetic fixtures provide independent fallback paths. No bank API or payment gateway is connected.

OpenAI Codex and Anthropic Claude were used during development, documentation and review. Model recommendations in private planning notes do not establish the actual model used for every session; no unverified model attribution is made here. These development tools do not make runtime payment decisions. Runtime decisions use explicit verification rules and authorized human actions.

Receipts, customers, accounts and bank credits in the included fixtures are synthetic. Public feedback is not used as application or model input. No purchased UI template assets or internal planning attachments are included in this source release.

This declaration preserves truthful competition disclosure; it is not an official completed submission form. Transfer verified details into the organizer's required template before submission.

V4 uses the existing system font stack. The story page lazy-loads Three.js 0.186.1; its MIT license is retained in apps/web/THIRD_PARTY_NOTICES.md. User-supplied visual references informed the implementation, but their HTML runtimes, embedded fonts and original attachments are not included. Browser WebGL is a local presentation feature, not a paid inference request.

The 2026-10-29 finalist implementation session used OpenAI Codex with GPT-6.1 Sol for code, integration tests and documentation. Its automated tests used isolated local PostgreSQL schemas and synthetic data; Telegram requests/replies were mocked and no paid inference calls were made by that session. Recommendations for other models are separate from actual recorded use. New sponsor credits have not been verified as redeemed by this code session.
